사용 방법

1. 칸 선택

실제 제비판에서 선택한 위치와 같은 칸을 누릅니다. 행과 열 위치가 선택 정보에 표시됩니다.

2. 결과 기록

15·5·3·2토큰 또는 1토큰 B/C○ 중 실제로 공개된 결과를 입력합니다. 잘못 입력한 경우 기록 취소가 가능합니다.

3. 힌트 기록

2토큰 이상이라고 알려진 정확한 위치가 있다면 해당 칸에 2+ 힌트를 표시합니다. 조건에 맞춰 EV가 다시 계산됩니다.

표시되는 EV는 확률을 이해하기 위한 정보입니다. 특정 칸 선택이나 유료 참여를 권하는 기능은 제공하지 않습니다.

계산 원리

초기 판은 49장으로 가정합니다. 구성은 15토큰 1장, 5토큰 2장, 3토큰 6장, 2토큰 10장, 1토큰 B 18장, 1토큰 C○ 12장으로 총 93토큰입니다.

기본 기대값

아무 정보가 없는 새 판의 평균은 총 토큰을 총 제비 수로 나눠 계산합니다.

93 ÷ 49 ≈ 1.898

위치 정보

2+ 힌트는 2·3·5·15만 후보로 사용합니다. C○의 좌우 칸은 C○ 후보에서 제외하는 간이 조건부 모델을 적용합니다.

현재 모델은 알려진 제비 종류와 직접 입력한 위치 정보를 기반으로 합니다. 12개의 C○가 7×7 전체에서 비인접하도록 배치되는 모든 경우를 완전 열거하는 정밀 베이지안 모델은 아직 적용하지 않았습니다.

사이트 소개

이 사이트는 7×7 확률 판의 상태를 기록하고 기대값 계산 과정을 쉽게 확인하기 위한 비공식 분석 도구입니다. 특정 게임의 공식 서비스가 아니며, 상표권자의 공식 사이트 또는 제휴 서비스임을 의미하지 않습니다.

데이터 처리

현재 버전은 회원가입이나 서버 데이터베이스를 사용하지 않습니다. 입력한 판 상태는 브라우저의 localStorage에만 저장되어 같은 브라우저에서 다시 열었을 때 복원됩니다. 자세한 내용은 개인정보 처리 안내를 확인하세요.
