개인정보 처리 안내

최종 업데이트: 2026-09-17

현재 제비EV는 회원가입, 자체 서버 또는 자체 데이터베이스를 사용하지 않습니다.

브라우저 저장 정보

사용자가 입력한 제비판 상태는 편의를 위해 해당 기기의 웹 브라우저 localStorage에 저장될 수 있습니다. 이 정보는 현재 사이트 운영자의 서버로 전송되지 않습니다. 브라우저의 사이트 데이터 삭제 기능을 이용하면 저장된 상태를 지울 수 있습니다.

광고 및 분석 서비스

현재 배포본에는 제3자 광고 또는 방문자 분석 코드가 포함되어 있지 않습니다. 향후 광고나 분석 서비스를 도입하는 경우 실제 사용되는 서비스와 데이터 처리 내용을 반영하여 이 안내를 업데이트해야 합니다.

외부 서비스

사이트가 GitHub Pages 등 외부 호스팅 서비스를 통해 제공되는 경우 해당 호스팅 사업자가 접속 로그 등 기술적 정보를 자체 정책에 따라 처리할 수 있습니다.
